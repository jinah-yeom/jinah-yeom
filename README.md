## 핵심 역량
 
- 디자인 시스템 재구축 — MUI에서 자체 시스템으로, 토큰 설계·컴포넌트 라이브러리·문서 사이트
- Token Studio → Style Dictionary → CSS 변수로 이어지는 토큰 파이프라인 설계
- Figma Code Connect 기반 디자인-코드 1:1 매핑 운영
- 서비스 정책 · PRD 작성과 화면 설계 — 정책을 먼저 세우고 화면을 그리는 순서

## 일하는 방식
 
- **토큰은 단일 소스** — 하드코딩된 스타일 값은 시스템의 부채로 보고, 위반이 리뷰가 아니라 빌드에서 드러나는 구조를 만듭니다
- **화면보다 정책 먼저** — 얽힌 기능은 규칙표부터 만들고, 개발자가 묻기 전에 문서에 답이 있는 상태를 목표로 합니다
- **도구를 만드는 것도 디자인** — 반복 검증은 사람이 아니라 구조가 하도록, 검사 스크립트와 자동화 스킬을 직접 만듭니다
